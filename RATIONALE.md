My design rationale for this came from just using as many flexible elements as necessary to make everything scale with different screen sizes.  It utilizes cards, bootstrap 5, and other css styled elements to keep styling the same across the different components and pages.  I only opted to use the one image under the hero header for the initial history page.  I made sure to include an aria-label as well to make it accessible.  Overall, these pages should look proper on any device as the resolution changes.  I did I went with a Desktop first design as well since thats what I would expect someone to view this page on.  Although the image does appear to fit better on mobile.  I organized the css by section, with a base level format for the overall styling, then broke it down by hero header, header, div so on.
